# 游戏文本提取 / 装回工具

把 LiLiM / Le.Chocolat 引擎游戏的 `scr.aos` 里的剧本文本导出成可翻译的文本文件，
译好后再装回去。导出的文本每条两行：上一行是原文（只读），下一行填译文。

已验证的游戏：

| 游戏 | 归档 | 脚本数 | 导出条目 |
|---|---|---|---|
| 恋する少女（ドール）と想いのキセキ | `scr.aos` 2,576,449 字节 | 284 | 81,547 |
| あい☆きゃん | `scr.aos` 1,760,901 字节 | 149 | 53,631 |

同引擎的其他作品可以试，但**必须先看工具报告里有没有报错**——遇到没见过的脚本写法
时工具会明确报错停下，不会悄悄漏掉。

## 需要装什么

Python 3.11 或更新版本。**没有任何第三方依赖**，装好 Python 就能跑。

想用拖放的话可以装 `tkinterdnd2`（`pip install tkinterdnd2`），不装也能用，
界面会提示点「浏览…」选文件。

## 怎么跑

三种方式，产出完全一样。

**图形界面**（推荐，双击即可）

```
python run_gui.py
```

**拖放**：把 `scr.aos` 拖到 `disassembler.py` 图标上，产物出现在归档所在目录的
`output\` 里。译好后把 `output` 目录拖到 `assembler.py` 图标上。

**命令行**

```
python disassembler.py "D:\游戏目录\scr.aos" -o "D:\游戏目录\scr_text"
python assembler.py "D:\游戏目录\scr_text"
```

命令行常用参数：

```
-o 目录              指定产物放哪（默认在归档旁边建 output\）
--texts              只出翻译用的文本，不出 ASM 清单
--asm                只出 ASM 清单
--source-encoding    原文编码，默认 cp932
--target-encoding    译文编码，中文一般填 gbk
--dry-run            （装回时）只看会改什么，不写文件
```

## 产出的文件都是什么

```
texts\      翻译用的双行文本，一个脚本一个文件，目录结构与原档一致
texts\_index.tsv  总览：哪个脚本对应哪个文本文件、有多少条
asm\        脚本清单，改游戏逻辑才需要，翻译不用管
rebuilt\    装回后的 scr.aos，复制回游戏目录用
reports\    各项检查的结果，出问题时贴给开发者
```

## 双行文本怎么改

```
# idx=00000255 line=523 tag=msg speaker=ヨミさん
○00000255○msg○『キタ━━━（´∀｀）・ω・）』
●00000255●msg●『来了━━━（´∀｀）・ω・）』
```

规则只有三条：

- **`○` 开头那行不要动。** 它是校对用的原文，改了会被拒绝。
- **`●` 开头那行填译文。** 只改第三个 `●` 之后的内容，前面的编号和标签别碰。
- **不要删空。** 导出时译文行预先填的是原文，留空会被当成误删而报错。没翻的条目
  保持原样就行，装回后显示原文，随时可以再翻。

`speaker=` 是说话人，方便判断语气，工具不校验。

原文里有几种特殊写法，**必须原样保留**：

| 写法 | 意思 | 能不能动 |
|---|---|---|
| `\n` | 换行。原句在脚本里被拆成两行显示 | 位置可以挪，**数量必须一样** |
| `\t` | 制表符 | 保留 |
| `\\` | 一个真正的反斜杠 | 保留 |
| `{{01:02}}` | 不能直接显示的字节 | 数量和内容都不能变 |

`\n` 是唯一允许挪位置的：一句话原文断在哪里，译文可以断在别处，但不能把两行并成
一行、也不能多断一行——工具会检查数量，不一致就拒绝并告诉你原来有几处。

写了 `\x`、`\N` 这种工具不认识的转义会直接报错，不会被当成普通文字混进去。

有些条目标了 `policy=frozen`（素材名、跳转标签），改了会被拒绝——它们照常导出是为了
让你能发现有没有标错。标 `policy=review-required` 的是立绘表情标签之类不确定是否
显示在游戏里的内容，可以先不管。

**选项只导出一次。** 同一个选项在脚本里常常写好几遍（调试分支、正常分支、
清单注释各一份），工具只让你翻一次，装回时自动写回全部位置，不会出现同一个
选项翻得不一样的情况。选项的「」括号、对齐空格和好感度标记不在可编辑范围内，
你只需要翻括号里的正文。

## 改完怎么装回去

界面上点「装 回 游 戏」，或者命令行跑 `python assembler.py <文本目录>`。

点下去之后会先出一个确认框，写清楚要改多少条、长度变化多少、输出到哪，
可以取消。确认后重建的 `scr.aos` 出现在 `scr_rebuilt\`（命令行下是
`<输出目录>\rebuilt\`）。

**把这个文件复制回游戏目录，覆盖原来的 `scr.aos`。原件建议先备份。**
工具本身永远不会改你的原始文件。

译文变长没问题，比原文长一倍也可以，工具会自动处理偏移。

## 报错怎么办

工具报错时会指出具体是哪个文件的第几条，按下面处置。

**译文文件检查不通过**（装回时最常见）

| 报错里的关键字 | 意思 | 怎么办 |
|---|---|---|
| `src_sha256 与当前 IR 不符` | 用旧文本文件配新导出的了 | 重新导出一次，把译文抄过去；或确认归档没被换过 |
| `原文行与 IR 不一致` | `○` 那行被改了 | 按报错里给的 IR 值把原文行改回去。编辑器自动把半角转全角、改引号、删行尾空格都会触发 |
| `译文行为空` | `●` 那行被删空了 | 填回内容，不翻就把原文抄回去 |
| `标记 frozen 却被改动` | 改了不该改的条目（素材名等） | 改回原样 |
| `占位符集合被改动` | `{{XX}}` 被删了或改了 | 按原文行的占位符补回去，大小写也要一致 |
| `换行数被改动` | `\n` 被删了或多加了 | 按报错里说的处数补回去；位置可以挪，数量不能变 |
| `无法识别的转义` | 写了 `\x` 之类工具不认的转义 | 只能用 `\n`、`\t`、`\\` 这三种 |
| `译文含 XXX 不可表示的字符` | 译文编码选错了 | 中文译文把「译文编码」改成 `gbk` 再重新导出 |
| `两行 idx 不一致` / `不是合法原文行` / `分隔符混用` | 行被改坏了，或 `○●` 混用 | 对照报错行号修；改坏太多就重新导出重抄 |
| `idx=… 不存在于该源` | 自己加了条目 | 删掉多加的 |
| `idx=… 重复` | 复制粘贴时重复了整块 | 删掉重复的 |
| `注释块与条目错位` | `# idx=` 注释和下面的条目对不上 | 删掉那行注释即可，注释不是必须的 |
| `分片 …：本工具只导出整片` | 文件头被改过 | 把文件头第三行改回 `# scope kind=all range=ALL part=1/1` |
| `target 编码 … 与方言不符` | 导出和装回用了不同的译文编码 | 两次用同一个编码 |
| `文件头不足 4 行` / `第 1 行不是 '# TEXT/N …'` | 文件头被删了 | 从新导出的同名文件里把前 4 行抄回来 |

**改了 ASM 清单之后报错**

| 报错里的关键字 | 怎么办 |
|---|---|
| `行数与新鲜投影不同` | ASM 清单不能增删行，把行数改回去 |
| `改动了非 .line 记录` / `改动了形态或行号` | 只能改引号里的文本，行首的 `L000123 .line` 之类不能碰 |
| `改动落在文本槽位之外` / `该行无文本槽位` | 这行的内容不是文本，本工具不支持改它 |

**读不出文件**

| 报错里的关键字 | 意思 |
|---|---|
| `不是 AOSv2` | 选错文件了，或这个游戏的归档格式不一样 |
| `无形态命中，signature=…` | 脚本里有工具没见过的写法。这不是你的操作问题，把报错整段贴给开发者 |
| `索引大小越界` / `条目 … 越界` / `解压长度不符` / `位流提前耗尽` | 归档文件损坏或被别的工具改过，换一份原始文件 |

**其他**

| 情况 | 怎么办 |
|---|---|
| 「装 回 游 戏」按钮点不动，提示「先输出文本」 | 先点「输 出 文 本」 |
| 提示「请至少选择一种输出」 | 两个勾选项至少勾一个 |
| 提示「此文件暂不支持装回」 | 工具自检发现这个归档不能安全重建，导出的文本只能看，不要装回 |
| 确认框里列出「冲突」 | 同一句话在双行文本和 ASM 清单里改成了两个样子，改成一致或只留一处 |
| 确认框显示「没有检测到任何改动」 | 译文还没改，或改的文件不在「从」指定的目录里 |
| `校验未通过，未产出文件` | 重建结果没通过自检，文件留在临时目录供排查，游戏目录和原件都没动。把 `reports\` 打包给开发者 |
| `找不到源归档 …，请用 --archive 指定` | 命令行下加 `--archive "D:\游戏目录\scr.aos"` |

## 已知限制

- **只支持 `.aos` 归档里的 `.scr` 脚本。** `grp.aos`（图片）、`cv.aos`（语音）不处理，
  图片上的文字改不了。
- **不能增删脚本、不能改游戏逻辑流程。** 能改的是文本内容；ASM 清单只允许改其中的
  字符串，改指令会被拒绝。
- **`cglist*.dat` / `hmlist*.dat` 原样保留**，里面的字段含义没有分析，不提取也不改动。
- **注释里的文本一般不提取。** 例外是 `#//①「…」` 形式的选项清单（会提取）。其他注释
  （原台词参照、路由说明、说话者备注）是开发者写给自己看的，游戏里看不到。
- **立绘表情标签**（1,456 条，形如 `ｔａ０１ａａａ１通常`）不确定游戏内是否显示，
  标为「需确认」照常导出，你可以自行决定要不要翻。
- **跨文件的重复选项不合并。** 同一个选项出现在不同脚本文件里时，每个文件各有一条，
  需要各自翻译（这样每个文件都能独立交给不同的人）。
- **只在上面表格里的两部作品上验证过。** 同引擎其他作品能不能用取决于脚本写法是否
  一致，遇到没见过的写法会明确报错而不是漏抽。
